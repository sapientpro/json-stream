# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to
[dmytro.kulyk@sapient.pro](mailto:dmytro.kulyk@sapient.pro).
Please avoid public issues or pull requests that disclose an unpatched vulnerability.

Include the affected package version, runtime, a minimal reproduction, and the
expected security impact. For parser issues, include input and chunk boundaries,
selectors, and relevant options. Remove credentials and other sensitive data.

Reports are assessed by the maintainers. A fix and any public advisory will be
coordinated with the reporter where possible. Response and remediation times are
not guaranteed.

## Versions

Report issues affecting the latest stable 2.x release or the current 3.x
prerelease. Prereleases are still under development; a fix may require upgrading
to a newer prerelease. Older versions may require upgrading to receive a fix.
